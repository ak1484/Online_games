# Deployment Guide

1. Finalize the game prototype in `dev/[game-name]/`
2. Confirm the deploy checklist in `agents/shared/deployment-checklist.md`
3. Copy the production-ready folder to `prod_games/[game-name]/`
4. Add `live-url.md` with the final URL and deployment details
5. Keep the deployment notes up to date for future hosting changes
