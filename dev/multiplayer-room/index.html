How to play

This multiplayer prototype is a turn-based click-to-claim board game.

  1. Create a room and share the room code with another player.
  2. Join the same room code from another browser or device.
  3. Players take turns clicking empty cells to claim them.
  4. Each claimed cell is shown in that player's color and displays the player number.

Winning

The game ends when all board cells are claimed. The player who has claimed the most cells wins.

If both players have the same number of claimed cells, the game is a tie.
